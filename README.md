# Website

A responsive website designed for Lentes Express, an optical store .

## Features

- Responsive HTML5 and CSS3 design
- Modern homepage layout
- Featured eyewear section
- Image carousel
- Google Maps location
- Contact information
- Google Reviews section
- Clean and accessible interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Purpose

This project was created to practice front-end web development while designing a professional website for a local optical business.
